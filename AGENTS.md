# MystoraX host package contract

MystoraX is a front-neutral access layer. Use `use-mystorax` for the universal
contract and `use-mystorax-science` for the sole optional Science extension.

Never duplicate live capability catalogs in package documentation. Discover
the current models, modes, tools, connectors, limits, specialists, and compute
targets through MystoraX. Never expose credentials or silently fall back.
