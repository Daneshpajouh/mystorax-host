# MystoraX host package 3.1.0

This repository is the front distribution package, not a second runtime or
capability catalog.

Claude Science imports exactly two Agent Skills from `skills/`:

- `use-mystorax`
- `use-mystorax-science`

The universal remote MCP surface is `https://mystorax-api.parallex.ca/mcp`.
Current capability truth comes from `/capabilities`. Retired Axiom, CompBio,
Science OS, and legacy Conductor skill trees are not published.
