# MystoraX skill index

| Task | Skill | Call |
|---|---|---|
| Discover and invoke a verified web author or CLI | `use-mystorax` | `capabilities` then `invoke` |
| Use scientific connectors, tools, specialists, compute, or evidence workflows | `use-mystorax-science` | `capabilities`, select `science`, then `invoke` |

Models, modes, connectors, tools, specialists, and limits are never copied into
this package. The live MystoraX catalog is authoritative.
